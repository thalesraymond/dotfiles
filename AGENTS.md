# Dotfiles Agent Notes

Personal Arch/CachyOS Linux desktop configuration managed with GNU Stow.

## Deploy / inspect changes

- Deploy **all** packages: `stow *` from repo root.  
  Top-level directories are Stow packages; top-level files (`fix-cedilla`, `pkglist.txt`, `aurlist.txt`, screenshots, etc.) are **not** deployed.
- Deploy one package: `stow <dir>` (e.g. `stow hypr`).
- Package layout mirrors the home directory: `hypr/.config/hypr/*` → `~/.config/hypr/*`, `zshrc/.zshrc` → `~/.zshrc`.
  Packages that exist only for reference/backups are **not** stowed (e.g. `hypr_full_old`).

## Generated / auto-managed files

Several config files are generated from templates. Do **not** hand-edit the output files—edit the templates/sources and rerun the generator.

| Output file | Generator / source | Template location |
|-------------|--------------------|-------------------|
| `hypr/.config/hypr/colors.lua` | Matugen | `matugen/.config/matugen/templates/hyprland-colors.lua` |
| `niri/.config/niri/dms-theme-sync.kdl` | DMS Theme Sync plugin | controlled from DMS settings |
| `niri/.config/niri/colors.kdl` | Wallust | `wallust/.config/wallust/templates/niri_colors.kdl` |
| `quickshell/.config/quickshell/qml_color.json` | Wallust | `wallust/.config/wallust/templates/qml_color.json` |
| `rofi/.config/rofi/wallust/colors-rofi.rasi` | Wallust | `wallust/.config/wallust/templates/colors-rofi.rasi` |
| `waybar/.config/waybar/wallust/colors-waybar.css` | Wallust | `wallust/.config/wallust/templates/colors-waybar.css` |
| `kitty`, `ghostty`, `btop`, `cava`, GTK, Qt, etc. colored outputs | Matugen / Wallust | `matugen/.config/matugen/templates/*` / `wallust/.config/wallust/templates/*` |

Wallust map: `wallust/.config/wallust/wallust.toml`.  
Matugen map: `matugen/.config/matugen/config.toml`.

## Component-specific notes

- **Hyprland**: configured via the Lua mode. Modules live under `hypr/.config/hypr/*.lua`; `hyprland.lua` is the entry point. The global `hl` is provided by Hyprland and is declared in `.luarc.json`. `colors.lua` is generated by Matugen.
- **Niri**: KDL files under `niri/.config/niri/`. `dms-theme-sync.kdl` is auto-generated by DMS for cursor/Qt env.
- **Quickshell**: QML-based shell. `shell.qml` loads modules; `config.json` controls features; `qml_color.json` is generated by Wallust.
- **Wallust / Matugen**: the source of truth for theming. Referenced by DankMaterialShell, Quickshell, Hyprland, Niri, Waybar, Rofi, Kitty, Ghostty, etc.
- **Vscode package**: has a `.stow-local-ignore` file; respects it when stowing.

## Files outside the Stow model

- `fix-cedilla`: a standalone helper script at repo root. Run/inspect directly; it is **not** symlinked by `stow *`.
- `pkglist.txt` / `aurlist.txt`: Arch package lists (official repos and AUR).
- `agents/.config/agents/AGENTS.md`: the user's universal agent profile for this workspace; changes here affect future OpenCode behavior.

## Verification

- There are no tests, linters, or build steps for this repo. Verify by checking Stow target paths and config syntax for the component you changed.
- Many configs take effect only after restarting the owning service/compositor, or by reloading in place where supported (e.g. `hyprctl reload`).

## Release workflow

`.github/workflows/tag-and-release.yml` pushes a new `YYYY.MM.DD.N` tag and creates a GitHub Release on every push to `main` as well as on manual dispatch.
